# Tic-Tac-Toe
A simple and interactive Tic Tac Toe game developed as a programming project. The game allows two players to play against each other on a 3×3 grid.

## About the Project

Tic Tac Toe is a classic two-player game where players take turns marking spaces on a 3×3 grid with **X** and **O**.

The objective is to place three of your symbols in a row — horizontally, vertically, or diagonally — before your opponent does.

This project was created to practice programming concepts such as loops, conditional statements, functions, arrays, and user input handling.

## Features

* Two-player gameplay
* Player 1 uses **X**
* Player 2 uses **O**
* Automatically detects the winner
* Detects a draw when the board is full
* Simple and easy-to-understand gameplay
* Runs directly from the terminal/console

## Technologies Used

* Python
* Python Standard Library
* VS Code or any Python IDE

## How to Play

1. Run the Python program.
2. The game displays a 3×3 board.
3. Player 1 enters a position and places **X**.
4. Player 2 enters a position and places **O**.
5. Players continue taking turns.
6. The game ends when:

   * A player gets three symbols in a row, or
   * All spaces are filled and the game is a draw.

## Winning Conditions

A player wins by getting three identical symbols in one of the following ways.

### Horizontal

```text
X | X | X
---------
O | O |
---------
  |   |
```

### Vertical

```text
X | O |
---------
X | O |
---------
X |   |
```

### Diagonal

```text
X | O |
---------
O | X |
---------
  |   | X
`
